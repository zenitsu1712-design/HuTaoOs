**HuTaoOS** là phiên bản tùy biến giao diện hệ điều hành lấy cảm hứng từ nhân vật **Hu Tao** (Genshin Impact) trong trang phục Yukata họa tiết cá vàng. Dự án được phát triển dựa trên nền tảng gốc **FurinaOS** của `Nguyenhailongmeowmeow`.

---

## 🎨 Tông màu chủ đạo (Color Palette)

- **Primary Color (Đỏ mận):** `#A8232B`
- **Secondary Color (Xanh gợn nước Yukata):** `#7BA4B5`
- **Accent Color (Kẹo hồ lô / Cá vàng):** `#E03E3E` / `#F26419`
- **Background Dark (Nâu trầm):** `#1E1A1D`
- **Background Light (Trắng xám):** `#F7F9FB`

---

## 🚀 Hướng dẫn cài đặt nhanh

```bash
# 1. Clone repository
git clone [https://github.com/zenitsu1712-design/HuTaoOS.git](https://github.com/zenitsu1712-design/HuTaoOS.git)
cd HuTaoOS

# 2. Cấp quyền thực thi cho script cài đặt
chmod +x scripts/install.sh

# 3. Chạy script áp dụng giao diện
./scripts/install.sh
